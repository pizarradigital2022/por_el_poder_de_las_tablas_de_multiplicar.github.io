📜 REGLAS DE LACONTIENDA (¡Escucha con atención, guerrero!)

Skeletor intenta descifrar los códigos numéricos ancestrales para entrar al Castillo de Grayskull. ¡Solo la velocidad mental con las tablas de multiplicar salvará el universo!

  • 1. El Pulsador: Cuando aparezca el desafío de multiplicación, calculad rápido. El primer equipo en pulsar congelará el reloj. El bando de He-Man (Izquierda)strong> usa la tecla 'A' y el bando de Skeletor (Derecha)strong> usa la tecla 'L'.
  • 2. Invocación del Poder: Al pulsar, tendréis 10 segundos para introducir el producto exacto y confirmar con OK (o pulsar Enter). Acertar otorga +100 puntos.
  • 3. Contraataque de Eternia (Rebote): Si falláis o se agota el tiempo, perderéis 50 puntos. El ataque se volverá inestable y se activará un **REBOTE DE 5 SEGUNDOS** donde el rival podrá pulsar para reclamar los 100 puntos.
  • 4. Siguiente Desafío: Si nadie aprovecha el rebote o el rival también falla, el portal cósmico cambia y se genera una nueva operación.
